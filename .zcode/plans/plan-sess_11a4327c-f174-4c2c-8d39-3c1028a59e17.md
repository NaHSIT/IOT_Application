# UI 重设计计划：智能家居工具风 + 公共 CSS + 深色模式

## 设计基调（米家/鸿蒙智慧生活式）

- **配色**：浅灰背景（#f5f6f7）+ 纯白卡片；单一主色（蓝 #3478f6）只用于选中态、关键操作和在线状态；语义色（绿/黄/红）仅用于状态表达。深色模式：#121212 背景 + #1e1e1e 卡片，通过 `prefers-color-scheme` 自动切换（CSS 变量实现双主题）。
- **形态**：卡片圆角统一 14px、1px 细边框代替光晕阴影；**全面移除发光圆点（`shadow-[0_0_8px_...]`）、毛玻璃底栏、`tracking-widest` 全大写标签、2rem 大圆角头部**；字重只用常规/中等两档。
- **图标**：保留 FontAwesome，传感器图标用小尺寸中性色块或单色，去掉五颜六色的淡彩底块。
- **图表**：Chart.js 保留，去掉渐变填充和夸张动画，改为细折线 + 低透明度纯色填充，颜色走主题变量。

## 技术改造

1. **新建 `assets/www/css/common.css`**：设计变量（颜色/圆角/间距，含深色主题覆盖）+ 基础样式 + 组件类（`.card`、`.btn`、`.bottom-nav`、`.page-header`、`.modal`、`.toast`、`.switch`、`.tabs`、`.table`、表单控件、状态色 `.st-ok/.st-warn/.st-alarm` 等）。
2. **逐页移除 Tailwind CDN**，静态标记和 JS 内联模板字符串全部改写为语义类；`config.js` 的 `COLOR_CLASSES` 与各页 JS 动态拼接的 Tailwind 类（如 `bg-${color}-50`）改为 common.css 中定义的语义类。
3. **严格保留 DOM 契约**（功能不回归的前提）：所有元素 id（含动态 `sensor-val-<id>`、`toggle-<id>` 等）、内联 onclick 全局函数、`localStorage` key、URL 参数、`AndroidApp` JS 桥、安全区 padding（`.pb-safe`）全部不变；`onenet.js` 不动。
4. Chart.js 与 FontAwesome 的 CDN 链接锁定具体版本，消除未锁版本的隐患。
5. 顺带清理：死代码 `modal-enter`、失效的 `py-4.5` 类、`CHART_COLORS` 重复色表（收敛到 common.css/config.js）。
