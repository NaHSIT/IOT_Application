## 四、测试过程中发现并已修复的问题

| 问题 | 修复 |
|---|---|
| 监测页卡片内 `.sensor-row` 遗留类覆盖 flex 布局，图标块掉到文字下方 | 删除遗留类 |
| `.btn` 未禁止换行，设置页添加按钮文字竖排 | `.btn` 增加 `white-space: nowrap` |
| common.css 缺 `.grid-cols-6`，设备弹窗图标选择器变单列 | 补充定义 |
| 缺 `.overflow-y-auto`，设置页设备弹窗内容溢出压住底部按钮 | 补充工具类；弹窗改为 flex 列布局（内容区独立滚动、底栏固定） |
| 弹窗显隐动画用双层 `requestAnimationFrame`，真机 WebView 上弹窗停留透明态未显示 | 统一改为 `setTimeout(30ms)`，并为遮罩补 `pointer-events` 兜底 |
| 视频页全屏退出按钮残留 Tailwind 任意值类（`z-[10000]` 等） | 改为语义类 `.video-exit` |
| 设置页表单单元文字被 flex 居中 | 新增 `.cell-form` 组件类 |
| 设置页分组标题与添加按钮挤压换行 | 标题与按钮拆为两行 |
| 控制页顶栏硬编码「设备在线」假状态 | 绑定真实同步结果（在线/离线/未连接三态） |
| 工具类缺失：`.text-3xl` `.opacity-30` `.py-20` `.gap-6` `.w-4/.h-4/.w-5` `.overflow-x-auto` 等 | 全部补充并复检通过 |

## 五、已知限制（非缺陷）

1. 假 OneNet 凭证下 `getLatestData` 返回失败属预期行为，数据区显示「--/获取中」。
2. 深色模式跟随系统 `prefers-color-scheme` 自动切换，暂未提供应用内手动开关（规划后续版本）。
3. Chart.js 与 FontAwesome 仍为在线 CDN，完全离线首次加载图表不可用（字体/布局不受影响）。
